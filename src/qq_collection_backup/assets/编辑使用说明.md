# 收藏网页编辑

1. 双击本目录的 **QQ收藏编辑器.exe**。它会在默认浏览器中打开收藏网页，无需安装 Python，也无需登录 QQ。
2. 展开一条收藏，再展开 **编辑标题与正文**。可以修改标题、补充文字、删除或重排正文；换行与代码原样保存。
3. 点击 **保存并同步 Markdown**，看到“已保存，Markdown 已同步”后即可关闭。对应笔记仍在 `Obsidian笔记库` 原有位置，文件名和收藏 ID 不变。

直接双击 `收藏分类阅读.html` 可以查看最后保存的文字；浏览器的普通本地页面无法自行写入磁盘，因此要保存到 Markdown，请从编辑器 EXE 打开。编辑器只在本机运行，关闭网页不等于关闭服务；用页面顶部“关闭编辑服务”退出。

## 保存范围

保存会更新对应 `.md`、`本地编辑.json`、`分类原始数据.json` 中的独立编辑层和网页内的数据。原始 QQ 正文仍保留在原始记录里，QQ 数据库不会被改写。这不是向 QQ 云端同步。

“调整这条的分类与标签”从编辑器打开时也会直接保存到 Markdown 属性；直接打开 HTML 时仍是浏览器分类草稿，需要导出调整文件。正文改动后，未重新确认的分类会标为待复核。

**Excel、笔记库 ZIP 和 bz 导入包是生成时的快照，不会随着每次网页保存即时重打包。** 以网页和解压后的 Markdown 为当前版本；再次生成整理结果时会合并本地编辑，再更新这些快照。已导入其他软件的副本不会自动更新。

## 保留修改和冲突

- 每次保存前的笔记在 `本地编辑历史`，按时间留存。
- 重新生成分类结果会按收藏 ID 保留 `本地编辑.json` 中的文字；QQ 原文同时变化时保留本地版本，并提示对照新原文合并。新库不再出现的条目不会抹去它的编辑记录，旧笔记保存在上一版完整目录中。
- 若笔记在其他软件中改动，打开编辑区会尝试读入其“正文/原始正文”代码块；请核对后保存。该代码块结构被改掉时，编辑器会停止并提示手动合并。自定义的其他章节、属性和排版请保留备份，网页保存会重新生成标准笔记格式；修改前的整份笔记保留在历史目录。
- 多窗口同时编辑时，较晚提交的旧版本会被阻止，编辑区文字仍保留；请另行复制文字，再重新载入合并。
- 更新整理结果前请先关闭编辑服务。跨电脑移动时，请复制**整个收藏分类整理目录**，不要只复制 HTML 或 EXE。`本地编辑.json` 与 `本地编辑历史` 一起保留。

## 单独携带编辑器

EXE 本身不含个人收藏。放到其他已生成的收藏分类目录里即可使用；未检测到目录时会弹出文件夹选择框。编辑器不读取 QQ 安装目录、不访问好友列表，也不连接外网。
