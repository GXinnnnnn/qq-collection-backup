# 使用说明

先登录本机 NT 版 QQ，并打开收藏夹。选择正确账号与独立输出目录，点击“一键备份收藏”。软件仅处理本机已缓存内容；不调用服务器获取其他收藏。

默认输出位于该 QQ 账号文件夹中，与 `nt_qq` 同级的 `QQ本地备份`。成功后恢复本机上次保存位置；手动选择数据库时应确保它属于自己的目标账号。不要把输出放进 `nt_db` 或包含源数据库的目录。

## 命令行

```powershell
qq-collection-backup --export --db-dir "实际路径\账号\nt_qq\nt_db" --output "D:\我的收藏备份" --datasets collection
```

文档目录通过系统特殊路径发现；示例路径仅是占位，不是软件固定路径。运行 `qq-collection-backup --help` 查看参数。

## 纯文件模式

如果不希望程序读取 QQ 进程内存，可以提供已有的、具有访问授权的密钥映射或解密后的 `collection.db`：

```powershell
qq-collection-backup --export --file-only --db-dir "本地数据库文件夹" --output "本地输出文件夹" --keymap "已有的keymap.json"
```

明文 SQLite 收藏库不需要 `--keymap`。密钥不匹配时停止该库的导出并保留旧版；不会在纯文件模式下改为读取进程。密钥映射至少包含一条 `salt` 和 `key` 的本地记录；本仓库不提供真实密钥示例。

## 编辑与更新

打包版完成备份后打开本地编辑网页。可编辑标题和多行正文，点击“保存并同步 Markdown”；完成提示出现后，文字已写入对应笔记、独立编辑记录和网页。

源数据库不会回写，也不会向 QQ 云端同步。Excel 是生成时快照，重新导出时刷新。其他软件已经导入的副本不自动更新。

重新导出前关闭编辑服务。保持同账号、同输出目录；网页修改按收藏 ID 继承，QQ 原文也变化时保留本地文字并提示合并。新库未出现的条目保存在旧版本中，独立编辑记录不会主动抹除。

在其他软件直接编辑的正文，网页会检查对应 Markdown 文件变化并尝试读入标准正文代码块。自定义属性、其他章节和排版不是通用双向同步；网页保存会生成标准格式，并在历史中保留修改前的文件。跨电脑使用时复制整个结果文件夹。

## 常见问题

- 未检测到账号：使用手动选择 `collection.db` 或账号文件夹，确认系统文档目录配置正确。
- 未检测到 QQ：先在这台电脑登录正确账号并打开收藏。
- 主进程拒绝访问：尝试以普通方式重开 QQ，或在理解原因后自行决定是否以管理员身份运行工具。不要关闭系统保护。
- 未找到密钥或格式不支持：当前 QQ 版本可能不兼容；保留旧结果，提交脱敏的错误文字和版本号即可，不提交数据库或密钥。
- 没有正文或附件：本机可能未缓存；工具不会联网补齐。缩略图不会伪装成原图。
