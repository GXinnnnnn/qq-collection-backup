# 兼容性

- 平台：Windows 10/11 x64；源码与发行版使用 Python 3.12。
- 本地验证过 NT QQ Windows `9.9.37.54395` 的收藏缓存提取、14 个收藏分组及无详情缓存表的情况。该验证不代表其他机器或后续版本均兼容。
- 支持 `collection_list_info_table`、可选的 `content_list_info_table` 和 `group_list_info_table`。缺失详情缓存表时保留列表文字与完整性说明。
- 已实现 QQ NT 容器、已知页面预留区形式、WAL 已提交帧校验及 SQLite 完整性检查。无法支持的格式应报错，不能静默当成成功。
- 本地验证数据不发布，回归测试仅使用人工构造样本。真实内容可能包含截断、未知字段、缺失附件和旧缓存；不保证全部收藏都被本机缓存。
