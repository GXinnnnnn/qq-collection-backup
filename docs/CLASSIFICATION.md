# 分类、标签与检索

QQ 原分组、内容领域、用途性质、关键词标签是四个独立字段。QQ 分组保持原样；本地分类不回写 QQ。

## 手动整理

从编辑器打开网页，展开收藏，点击“调整分类与标签”：

- 领域与用途均可从常用选项中选择，或在下方输入新名称，各最多40字。
- 标签可自由输入或点击候选词，允许0—3个，每个最多24字；不要求填满。
- 点击“保存分类与标签”，会写入对应 Markdown 属性、编辑记录和网页；刷新或下次备份仍保留。已有自定义名称会出现在后续选项中。
- 直接打开 HTML 时只保存浏览器草稿，需要导出调整文件；要直接同步 Markdown，请运行编辑器。

## 本地建议

新导出使用 QQ 分组作为独立线索，再结合完整的**本地缓存文字**、多个领域线索和清单结构生成初步分类。条目也可点击“生成本地建议”，查看依据，填入后确认保存。

这是离线规则功能，不是大模型语义理解：不联网、不上传、不调用云端 AI，不宣称能够准确识别所有反讽、梗、隐喻或跨作品讨论。建议始终标明“未逐条复核”；已有人工分类和精确匹配的语义复核记录优先保留。没有把握时保留“待辨识”，纯链接及无正文记录不会硬塞关键词。凭据格式只触发本地遮挡，不把密码本身提炼为关键词。

领域包括游戏、动画、漫画、漫威、影视与特摄、音乐、技术宅、学习与知识、生活、社会与人文、文学与情感、杂谈、个人资料等。用途另含数据整理、清单与推荐、教程与方法、备忘录、日记、摘要、观点讨论、生活吐槽、段子与玩梗、资源与链接和存档等。

## 检索

可组合 QQ 分组、领域、用途、标签、整理状态、年份和起止日期；搜索可限定标题、正文或标签与分类，并选择“包含所有词”或“包含任意词”。整理状态可筛选没有标签、领域用途待辨识、本地建议、待复核或 QQ 原文有更新等。

笔记库附带 `收藏检索.base`，供支持 Bases 的 Obsidian 打开，含领域、待复核、没有标签视图。Markdown 使用明确的 `domain`、`purpose`、`tags`、`keywords` 属性；标签语法规范化，但 `keywords` 保留可读文字。Excel 是生成时快照。

## 参考的方法

参考技能的组织方法与格式规范，没有打包或自动执行第三方技能：

- [Obsidian Markdown skill](https://github.com/obsidianmd/obsidian-skills/blob/main/plugins/obsidian/skills/obsidian-markdown/SKILL.md)：属性与可检索标签。
- [Obsidian Bases skill](https://github.com/obsidianmd/obsidian-skills/blob/main/plugins/obsidian/skills/obsidian-bases/SKILL.md)：按笔记属性组合筛选和分组视图。
- [Content Digestion skill](https://github.com/VinsonLiangyc/content-digestion/blob/main/SKILL.md)：区分分类标签、具体实体与概念，不虚构缺失信息。

本工具按用户需求限制为0—3个确切标签，保留原文及来源，不自动重写正文。
